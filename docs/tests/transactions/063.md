# 063. Ширина управляемой блокировки

Транзакции, журнал и блокировки · [Каталог и правила прогона](../README.md)

## Методика

При независимых данных двух сеансов расширить только область захвата первого.

## Что измерять

Область, режим, длительность ожидания.

## Как читать результат

Появление конфликта на независимых ключах измеряет эффект избыточной ширины.
