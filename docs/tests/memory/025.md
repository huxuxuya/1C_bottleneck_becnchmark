# 025. Возврат из swap

Память и кэши CPU · [Каталог и правила прогона](../README.md)

> **Статус BSL-only:** описанная здесь прямая метрика требует управления или счётчика ОС/гипервизора, которого BSL не предоставляет. Проект не запускает внешний сборщик и не принимает его пакет. До новой BSL-only методики точный механизм этой проверки не измеряется. См. [границу возможностей BSL](../bsl-only-capabilities.md).

## Методика

Подготовить анонимный набор с контрольной суммой, создать давление, повторно обойти тот же набор.

## Что измерять

Swap-in, длительность обхода, задержки страниц.

## Как читать результат

Паузы с фактическим вводом из swap подтверждают стоимость возврата вытесненных страниц.

## Текущее состояние

Общий модуль "БенчмаркПроба025ВозвратИзSwap" содержит BSL-код анализа переданных структур и не запускает измерительную нагрузку для этого механизма. Он не считывает OS/гипервизорные показатели и не используется раннером как источник результата. YAxUnit-проверки подтверждают только расчёт на заданных входных данных.

В режиме проекта BSL-only "swap-in и major faults ОС" напрямую недоступна. Методика пока не даёт измерительного результата; до появления соответствующего платформенного API эту проверку нужно пометить «недоступно в BSL» либо отдельно спроектировать поведенческий BSL-прокси с более узким выводом.
