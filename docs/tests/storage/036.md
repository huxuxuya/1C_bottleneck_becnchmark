# 036. Случайное одиночное чтение

Хранилище · [Каталог и правила прогона](../README.md)

## Методика

Читать подготовленный широкий диапазон случайными блоками размером со страницу СУБД, QD=1.

## Что измерять

P50/p95/p99 завершения, фактическая QD.

## Как читать результат

Базовая задержка пути для зависимых чтений при выбранном режиме кэша.
