# 062. Управляемая блокировка по ключу

Транзакции, журнал и блокировки · [Каталог и правила прогона](../README.md)

## Методика

Два сеанса запрашивают конфликтующие режимы в одном пространстве блокировок 1С. Сравнить одинаковые и разные ключи.

## Что измерять

Ожидание, ключ, режим, владелец.

## Как читать результат

Ожидание только на совпадающем ключе идентифицирует конфликт управляемых блокировок.
