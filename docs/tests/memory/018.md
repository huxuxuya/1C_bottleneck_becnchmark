# 018. Задержки кэшей и DRAM

Память и кэши CPU · [Каталог и правила прогона](../README.md)

> **Статус BSL-only:** описанная здесь прямая метрика требует управления или счётчика ОС/гипервизора, которого BSL не предоставляет. Проект не запускает внешний сборщик и не принимает его пакет. До новой BSL-only методики точный механизм этой проверки не измеряется. См. [границу возможностей BSL](../bsl-only-capabilities.md).

## Методика

Увеличивать случайно перемешанную зависимую цепочку от нескольких КиБ до объёма выше LLC.

## Что измерять

Нс/доступ по размеру, при наличии промахи кэша.

## Как читать результат

Ступени кривой локализуют диапазон размеров, где дорожает обращение.

## Текущее состояние

Общий модуль "БенчмаркПроба018ЗадержкиКэшейDRAM" содержит BSL-код анализа переданных структур и не запускает измерительную нагрузку для этого механизма. Он не считывает OS/гипервизорные показатели и не используется раннером как источник результата. YAxUnit-проверки подтверждают только расчёт на заданных входных данных.

В режиме проекта BSL-only "аппаратные задержки кэшей/DRAM и cache misses" напрямую недоступна. Методика пока не даёт измерительного результата; до появления соответствующего платформенного API эту проверку нужно пометить «недоступно в BSL» либо отдельно спроектировать поведенческий BSL-прокси с более узким выводом.
