# 023. Ложное совместное использование линии

Память и кэши CPU · [Каталог и правила прогона](../README.md)

## Методика

Два закреплённых потока изменяют отдельные счётчики сначала в общей линии, затем в разнесённых линиях.

## Что измерять

Обновления/с, по возможности события когерентности.

## Как читать результат

Ускорение после разнесения при тех же операциях измеряет цену совместного владения линией.

## Реализация в проекте

БенчмаркПроба023ЛожноеСовместноеИспользование.СравнитьРазмещениеСчетчиков(Смежные, Разнесенные) проверяет одну и ту же пару закреплённых CPU, два потока, одинаковое число обновлений и заданные смещения счётчиков относительно размера cache line. Результат содержит медианную скорость обновлений и ускорение после разнесения; события когерентности учитываются, если они переданы.

Потоки и affinity создаёт внешний измеритель. YAxUnit проверяет адресную геометрию, контрольные суммы и расчёт скорости; реальные замеры ещё не внесены.
