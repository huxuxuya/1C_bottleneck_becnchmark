# 044. Кэш ОС

Хранилище · [Каталог и правила прогона](../README.md)

## Методика

Сравнить повторное чтение одного диапазона в buffered и direct режимах.

## Что измерять

Задержка, запросы к блочному устройству.

## Как читать результат

Разница и изменение числа I/O показывают вклад кэша ОС. Кэш массива может участвовать в обоих вариантах.
