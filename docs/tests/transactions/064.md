# 064. Блокировка строки СУБД

Транзакции, журнал и блокировки · [Каталог и правила прогона](../README.md)

## Методика

Удерживать обновление одной строки, вторым писателем менять ту же или другую строку.

## Что измерять

Граф СУБД, владелец, ресурс, время освобождения.

## Как читать результат

Доказать конфликт на уровне движка и проверить гранулярность по ресурсу ожидания.
