# 016. Первичное размещение страниц

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

## Методика

Инициализировать массив одним потоком либо по частям будущими владельцами. Расчёт после инициализации одинаков.

## Что измерять

Распределение страниц, длительность расчёта.

## Как читать результат

Изменение размещения и скорости вместе подтверждает чувствительность к first touch.
