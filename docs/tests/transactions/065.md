# 065. Время удержания ресурса

Транзакции, журнал и блокировки · [Каталог и правила прогона](../README.md)

## Методика

Добавить фиксированную паузу внутри транзакции после захвата, затем вынести ту же паузу после commit.

## Что измерять

Длительность удержания, время ожидания, очередь.

## Как читать результат

Сдвиг времени ожидания вслед за длиной удержания измеряет цену длинной транзакции.
