# 001. Скорость одного ядра

CPU и планировщик · [Каталог и правила прогона](../README.md)

## Методика

Прогреть код и данные, закрепить поток. Повторить зависимую арифметическую цепочку с одинаковой контрольной суммой на каждом доступном ядре.

## Что измерять

Нс/итерацию, CPU-время потока, циклы/итерацию.

## Как читать результат

Устойчивый разрыв между ядрами локализует асимметрию. Учитывать класс ядра и эффективную частоту.
