# 031. Первый вызов процесса

Рабочий процесс и кластер 1С · [Каталог и правила прогона](../README.md)

## Методика

Новый сеанс на новом процессе сравнить с новым сеансом на прогретом процессе при тёплой СУБД.

## Что измерять

Задержка первого вызова, PID, время старта процесса.

## Как читать результат

Дополнительная разница к пробе 030 локализует холодный старт процесса.
