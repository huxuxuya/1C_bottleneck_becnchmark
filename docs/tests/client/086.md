# 086. Распаковка ответа

Клиент и доставка результата · [Каталог и правила прогона](../README.md)

## Методика

Воспроизвести готовый ответ на клиенте без сети. Менять объём при фиксированной структуре.

## Что измерять

CPU, память, время до готовой коллекции.

## Как читать результат

Различия между рабочими местами локализуют цену клиентской распаковки.
