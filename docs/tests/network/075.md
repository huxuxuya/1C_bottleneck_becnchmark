# 075. Разрешение имени

Сеть и соединения · [Каталог и правила прогона](../README.md)

## Методика

Из клиентской среды разрешать реальное имя сервиса с холодным и прогретым результатом.

## Что измерять

Время ответа DNS, повторы, адрес, выбранный сервер.

## Как читать результат

Задержка до начала соединения локализует вклад разрешения имени.
