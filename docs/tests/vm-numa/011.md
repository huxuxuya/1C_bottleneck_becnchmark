# 011. Ожидание vCPU

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

## Методика

При постоянном расчёте в госте синхронно записывать ready хоста либо доступный steal гостя.

## Что измерять

Работа/с, ready по vCPU, steal, интервал накопления.

## Как читать результат

Рост ожидания при падении скорости поддерживает гипотезу конкуренции. Крупное окно не разрешает короткую паузу.
