# 033. Память открытого сеанса

Рабочий процесс и кластер 1С · [Каталог и правила прогона](../README.md)

## Методика

В один процесс ступенями добавлять прогретые простаивающие сеансы, затем закрывать.

## Что измерять

Прирост байтов/сеанс, остаток после закрытия.

## Как читать результат

Наклон кривой оценивает ёмкость по числу открытых сеансов при выбранном профиле.
