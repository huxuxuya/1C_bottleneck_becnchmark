# 056. Ожидание memory grant в SQL Server

СУБД и планы · [Каталог и правила прогона](../README.md)

## Методика

Добавлять параллельные запросы с воспроизводимой заявкой памяти.

## Что измерять

Requested/granted memory, RESOURCE_SEMAPHORE, время до исполнения.

## Как читать результат

Очередь выдачи памяти возникает до работы оператора. Отделять от spill в выполняющемся запросе.
