# 028. Насыщение одного rphost

Рабочий процесс и кластер 1С · [Каталог и правила прогона](../README.md)

## Методика

Подать тот же внешний поток и число сеансов в один и несколько прогретых процессов одного узла. Проверить фактические PID.

## Что измерять

Операции/с, задержка, очередь, CPU по PID.

## Как читать результат

Восстановление при распределении локализует чувствительность к концентрации работы в процессе.
