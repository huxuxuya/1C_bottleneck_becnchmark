# 021. Задержка памяти под нагрузкой

Память и кэши CPU · [Каталог и правила прогона](../README.md)

> **Статус BSL-only:** описанная здесь прямая метрика требует управления или счётчика ОС/гипервизора, которого BSL не предоставляет. Проект не запускает внешний сборщик и не принимает его пакет. До новой BSL-only методики точный механизм этой проверки не измеряется. См. [границу возможностей BSL](../bsl-only-capabilities.md).

## Методика

Держать одну зависимую цепочку и добавлять фоновый последовательный доступ заданной интенсивности.

## Что измерять

Нс/чтение относительно фактических фоновых ГБ/с.

## Как читать результат

Найти полосу, при которой возрастает задержка одиночного доступа.

## Текущее состояние

Общий модуль "БенчмаркПроба021ЗадержкаПамятиПодНагрузкой" содержит BSL-код анализа переданных структур и не запускает измерительную нагрузку для этого механизма. Он не считывает OS/гипервизорные показатели и не используется раннером как источник результата. YAxUnit-проверки подтверждают только расчёт на заданных входных данных.

В режиме проекта BSL-only "задержку DRAM под параллельной памятью нагрузкой" напрямую недоступна. Методика пока не даёт измерительного результата; до появления соответствующего платформенного API эту проверку нужно пометить «недоступно в BSL» либо отдельно спроектировать поведенческий BSL-прокси с более узким выводом.
