# 070. Полоса одного соединения

Сеть и соединения · [Каталог и правила прогона](../README.md)

## Методика

Передавать подготовленный большой буфер отдельно в каждом направлении.

## Что измерять

Полезные МиБ/с, CPU концов, retransmits.

## Как читать результат

Сравнить устойчивую полосу и асимметрию направлений.
