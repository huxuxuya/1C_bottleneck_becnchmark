# 026. Скорость BSL

Рабочий процесс и кластер 1С · [Каталог и правила прогона](../README.md)

## Методика

В одном прогретом серверном вызове выполнить фиксированный цикл над локальными переменными известных типов. Проверить сумму.

Для серверного запуска вызвать `БенчмаркПробы.Проба026_СкоростьBSL()`. Пилот удваивает пакет до длительности 100 мс либо 16 млн итераций. Затем выполняются два прогрева и семь новых серий; из них берётся медиана. Каждый пакет начинает с одинакового состояния, суммы повторов проверяются.

Первое значение в «Деталях» — округлённые условные МГц BSL по формуле 3000 × база / фактические нс на итерацию. База по умолчанию — 250 нс. Следом идут медиана, объём и млн итераций/с. При отключённой шкале или медиане менее 10 мс выводится причина отсутствия цифры. Для сверки рядом есть [фиксированный тест 001](../cpu/001.md). Обе цифры характеризуют скорость цикла, в итоговый балл из этой пары входит 026.

## Что измерять

Время обработчика/итерацию, нативный контроль 001.

## Как читать результат

Изменение только BSL при стабильной нативной пробе локализует регрессию относительно платформенного эталона.
