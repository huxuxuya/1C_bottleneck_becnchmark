# 067. Взаимоблокировка

Транзакции, журнал и блокировки · [Каталог и правила прогона](../README.md)

## Методика

Синхронизировать две сессии барьером после первого захвата, затем запросить второй ресурс в обратном порядке. Контроль использует единый порядок.

## Что измерять

Граф цикла, жертва, стоимость повтора.

## Как читать результат

Требуется наблюдаемый цикл или отчёт движка о deadlock. Таймаут учитывать отдельно.
