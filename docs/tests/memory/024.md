# 024. Синхронный reclaim

Память и кэши CPU · [Каталог и правила прогона](../README.md)

## Методика

Увеличивать набор в группе с ограниченной памятью. Разделить выделение адресов и первое касание страниц.

## Что измерять

Задержка выделения и касания, direct reclaim, memory PSI.

## Как читать результат

Порог, после которого сам выделяющий поток тратит время на освобождение памяти, задаёт предел набора.

## Реализация в проекте

БенчмаркПроба024СинхронныйReclaim.АнализироватьReclaim(Точки) сравнивает выделение и первое касание страниц при возрастающем размере набора в одном cgroup. Для каждой точки нужны три повтора; медианы Direct Reclaim и Memory PSI позволяют показать первую наблюдённую точку давления, отдельно от времени выделения и касания.

Лимит cgroup и нагрузку задаёт внешний исполнитель. Порог означает первую точку со свидетельством reclaim/PSI в измеренном диапазоне, а не универсальную ёмкость хоста. YAxUnit проверяет агрегацию и порядок точек; реальные замеры ещё не внесены.
