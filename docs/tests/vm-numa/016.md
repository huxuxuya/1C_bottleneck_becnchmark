# 016. Первичное размещение страниц

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

> **Статус BSL-only:** описанная здесь прямая метрика требует управления или счётчика ОС/гипервизора, которого BSL не предоставляет. Проект не запускает внешний сборщик и не принимает его пакет. До новой BSL-only методики точный механизм этой проверки не измеряется. См. [границу возможностей BSL](../bsl-only-capabilities.md).

## Методика

Инициализировать массив одним потоком либо по частям будущими владельцами. Расчёт после инициализации одинаков.

## Что измерять

Распределение страниц, длительность расчёта.

## Как читать результат

Изменение размещения и скорости вместе подтверждает чувствительность к first touch.

## Текущее состояние

Общий модуль "БенчмаркПроба016ПервичноеРазмещение" содержит BSL-код анализа переданных структур и не запускает измерительную нагрузку для этого механизма. Он не считывает OS/гипервизорные показатели и не используется раннером как источник результата. YAxUnit-проверки подтверждают только расчёт на заданных входных данных.

В режиме проекта BSL-only "фактическое размещение физических страниц" напрямую недоступна. Методика пока не даёт измерительного результата; до появления соответствующего платформенного API эту проверку нужно пометить «недоступно в BSL» либо отдельно спроектировать поведенческий BSL-прокси с более узким выводом.
