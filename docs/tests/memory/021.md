# 021. Задержка памяти под нагрузкой

Память и кэши CPU · [Каталог и правила прогона](../README.md)

## Методика

Держать одну зависимую цепочку и добавлять фоновый последовательный доступ заданной интенсивности.

## Что измерять

Нс/чтение относительно фактических фоновых ГБ/с.

## Как читать результат

Найти полосу, при которой возрастает задержка одиночного доступа.
