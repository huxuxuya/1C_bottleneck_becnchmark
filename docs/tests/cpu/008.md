# 008. Восстановление скорости после простоя

CPU и планировщик · [Каталог и правила прогона](../README.md)

## Методика

Менять паузу перед одинаковой серией вычислений. Измерять начало и последующие порции отдельно.

## Что измерять

Опоздание старта, нс/итерацию по порциям, эффективная частота.

## Как читать результат

Своевременный старт с медленными первыми порциями локализует потерю внутри исполнения. Частотный механизм требует метрик хоста.
