# 066. Цепочка блокировок

Транзакции, журнал и блокировки · [Каталог и правила прогона](../README.md)

## Методика

Создать три транзакции. Первая держит A, вторая держит B и ждёт A, третья ждёт B.

## Что измерять

Рёбра графа, идентификаторы транзакций, длительности.

## Как читать результат

Найти корневого владельца, включая ситуацию, когда он простаивает с открытой транзакцией.
