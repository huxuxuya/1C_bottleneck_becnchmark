# 005. Квота CPU

CPU и планировщик · [Каталог и правила прогона](../README.md)

## Методика

На стенде выполнять постоянный расчёт в группе с квотой, затем изменить только квоту.

## Что измерять

Время throttling, периоды ограничения, длительность порции.

## Как читать результат

Сдвиг пауз вслед за квотой и рост счётчика throttling указывают на ограничение группы.

## Нативное исполнение

`CPU_005_CPU_QUOTA` читает ограничения текущего процесса и разницу счётчиков до/после короткой вычислительной нагрузки. В Linux читает cgroup v1/v2 quota, период, число периодов и throttled time. В Windows сообщает заданный CPU-rate текущего Job Object, если платформа его раскрывает; этот API не предоставляет счётчик времени throttling. На macOS проба честно возвращает `Недоступно`, поскольку переносимого API для такого счётчика нет. Скорость нагрузки сама по себе квоту не доказывает.

Параметр `arg1=loadWindowMs` (10–10 000); автоматический набор — 250 мс. Тест не меняет ограничения процесса. Результат сохраняется как `NCPU005C` и `NCPU005S`.
