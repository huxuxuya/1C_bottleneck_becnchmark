# 060. Групповая фиксация

Транзакции, журнал и блокировки · [Каталог и правила прогона](../README.md)

## Методика

Повышать число исполнителей с независимыми транзакциями при том же объёме изменения на commit.

## Что измерять

Commits/с, flush/с, commits/flush, задержка.

## Как читать результат

Изменение группирования и выход на плато показывают предел при конкурентной фиксации.
