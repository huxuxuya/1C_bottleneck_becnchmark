# 017. Вытеснение памяти хостом

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

> **Статус BSL-only:** описанная здесь прямая метрика требует управления или счётчика ОС/гипервизора, которого BSL не предоставляет. Проект не запускает внешний сборщик и не принимает его пакет. До новой BSL-only методики точный механизм этой проверки не измеряется. См. [границу возможностей BSL](../bsl-only-capabilities.md).

## Методика

На тестовой ВМ повторить обход до, во время и после контролируемого давления памяти хоста.

## Что измерять

Balloon, host swap, guest swap, задержка обхода.

## Как читать результат

Разделять фактическую подкачку и изменение balloon. Влияние видно по задержке при активном механизме.

## Текущее состояние

Общий модуль "БенчмаркПроба017ВытеснениеПамятиХостом" содержит BSL-код анализа переданных структур и не запускает измерительную нагрузку для этого механизма. Он не считывает OS/гипервизорные показатели и не используется раннером как источник результата. YAxUnit-проверки подтверждают только расчёт на заданных входных данных.

В режиме проекта BSL-only "давление памяти и swap на хосте" напрямую недоступна. Методика пока не даёт измерительного результата; до появления соответствующего платформенного API эту проверку нужно пометить «недоступно в BSL» либо отдельно спроектировать поведенческий BSL-прокси с более узким выводом.
