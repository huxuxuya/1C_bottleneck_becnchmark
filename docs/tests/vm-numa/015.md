# 015. Межузловая полоса NUMA

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

> **Статус BSL-only:** описанная здесь прямая метрика требует управления или счётчика ОС/гипервизора, которого BSL не предоставляет. Проект не запускает внешний сборщик и не принимает его пакет. До новой BSL-only методики точный механизм этой проверки не измеряется. См. [границу возможностей BSL](../bsl-only-capabilities.md).

## Методика

При проверенном размещении читать большие буферы несколькими потоками по каждой паре узлов.

## Что измерять

Матрица ГБ/с, полоса на поток.

## Как читать результат

Направление с низкой устойчивой полосой локализует ограничение межузлового пути.

## Текущее состояние

Общий модуль "БенчмаркПроба015ПолосаNUMA" содержит BSL-код анализа переданных структур и не запускает измерительную нагрузку для этого механизма. Он не считывает OS/гипервизорные показатели и не используется раннером как источник результата. YAxUnit-проверки подтверждают только расчёт на заданных входных данных.

В режиме проекта BSL-only "межузловую полосу NUMA" напрямую недоступна. Методика пока не даёт измерительного результата; до появления соответствующего платформенного API эту проверку нужно пометить «недоступно в BSL» либо отдельно спроектировать поведенческий BSL-прокси с более узким выводом.
