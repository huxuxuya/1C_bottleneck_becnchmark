# 014. Задержка удалённой NUMA-памяти

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

> **Статус BSL-only:** описанная здесь прямая метрика требует управления или счётчика ОС/гипервизора, которого BSL не предоставляет. Проект не запускает внешний сборщик и не принимает его пакет. До новой BSL-only методики точный механизм этой проверки не измеряется. См. [границу возможностей BSL](../bsl-only-capabilities.md).

## Методика

Зафиксировать CPU и обходить зависимую цепочку локально и удалённо размещённых страниц. Проверить резидентность.

## Что измерять

Матрица нс/чтение для пар узлов.

## Как читать результат

Парная разница измеряет штраф удалённого доступа. Для вывода о физическом хосте проверить физическое размещение.

## Текущее состояние

Общий модуль "БенчмаркПроба014УдаленнаяNUMAПамять" содержит BSL-код анализа переданных структур и не запускает измерительную нагрузку для этого механизма. Он не считывает OS/гипервизорные показатели и не используется раннером как источник результата. YAxUnit-проверки подтверждают только расчёт на заданных входных данных.

В режиме проекта BSL-only "удалённую NUMA-локальность" напрямую недоступна. Методика пока не даёт измерительного результата; до появления соответствующего платформенного API эту проверку нужно пометить «недоступно в BSL» либо отдельно спроектировать поведенческий BSL-прокси с более узким выводом.
