# 013. Асимметрия vCPU

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

> **Статус BSL-only:** описанная здесь прямая метрика требует управления или счётчика ОС/гипервизора, которого BSL не предоставляет. Проект не запускает внешний сборщик и не принимает его пакет. До новой BSL-only методики точный механизм этой проверки не измеряется. См. [границу возможностей BSL](../bsl-only-capabilities.md).

## Методика

Закрепить одинаковых исполнителей по одному на vCPU, затем поменять исполнителей местами.

## Что измерять

Распределение времени порции по vCPU.

## Как читать результат

Если медленный результат следует за vCPU, локализована асимметрия размещения или планирования.

## Текущее состояние

Общий модуль "БенчмаркПроба013АсимметрияvCPU" содержит BSL-код анализа переданных структур и не запускает измерительную нагрузку для этого механизма. Он не считывает OS/гипервизорные показатели и не используется раннером как источник результата. YAxUnit-проверки подтверждают только расчёт на заданных входных данных.

В режиме проекта BSL-only "асимметрию производительности отдельных vCPU" напрямую недоступна. Методика пока не даёт измерительного результата; до появления соответствующего платформенного API эту проверку нужно пометить «недоступно в BSL» либо отдельно спроектировать поведенческий BSL-прокси с более узким выводом.
