# 016. Первичное размещение страниц

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

## Методика

Инициализировать массив одним потоком либо по частям будущими владельцами. Расчёт после инициализации одинаков.

## Что измерять

Распределение страниц, длительность расчёта.

## Как читать результат

Изменение размещения и скорости вместе подтверждает чувствительность к first touch.

## Реализация в проекте

`БенчмаркПроба016ПервичноеРазмещение.СравнитьПервичноеРазмещение(Однопоточно, ПоВладельцам)` сравнивает два варианта с одинаковым стендом, размером набора, полезным расчётом и контрольной суммой. Каждый вариант содержит ожидаемое и фактическое распределение объёма страниц по NUMA-узлам и не менее трёх длительностей последующего расчёта. Результат показывает долю страниц на целевых узлах, её изменение в процентных пунктах и изменение медианы времени расчёта.

Инициализацию с привязкой к CPU и чтение фактической карты страниц выполняет внешний измеритель. YAxUnit проверяет агрегацию контрольных данных; реальные замеры ещё не внесены.
