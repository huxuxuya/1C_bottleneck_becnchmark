# 021. Задержка памяти под нагрузкой

Память и кэши CPU · [Каталог и правила прогона](../README.md)

## Методика

Держать одну зависимую цепочку и добавлять фоновый последовательный доступ заданной интенсивности.

## Что измерять

Нс/чтение относительно фактических фоновых ГБ/с.

## Как читать результат

Найти полосу, при которой возрастает задержка одиночного доступа.

## Реализация в проекте

БенчмаркПроба021ЗадержкаПамятиПодНагрузкой.АнализироватьЗадержкуПодНагрузкой(Точки) связывает медианную задержку зависимого чтения с фактически достигнутой фоновой полосой. Целевые уровни нагрузки идут по возрастанию; фактическая полоса передаётся в каждом повторе. Сравнение требует нулевой достигнутой фоновой полосы, одинаковых стенда, набора, алгоритма, числа доступов и контрольной суммы, а также минимум три повтора на точку.

Фоновые потоки и замеры выполняются внешним измерителем. YAxUnit проверяет базовое сравнение и отказ при несовместимых наборах; реальные замеры ещё не внесены.
