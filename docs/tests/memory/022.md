# 022. Давление на TLB

Память и кэши CPU · [Каталог и правила прогона](../README.md)

## Методика

Обращаться к одной линии на страницу в случайном порядке. Сравнить обычные и крупные страницы при том же объёме и размещении.

## Что измерять

Фактический размер страниц, page walks, нс/доступ.

## Как читать результат

Снижение обходов таблиц страниц вместе с задержкой подтверждает вклад трансляции.

## Реализация в проекте

БенчмаркПроба022ДавлениеНаTLB.СравнитьРежимыСтраниц(ОбычныеСтраницы, КрупныеСтраницы) сравнивает одинаковый набор и число случайных доступов. Для каждого фактического размера страницы нужны минимум три замера задержки и page walks; результат нормализует обходы таблиц страниц на 1000 доступов.

Включение страниц, подтверждение их фактического размера и аппаратные события выполняет внешний измеритель. YAxUnit проверяет расчёт и сопоставимость вариантов; реальные замеры ещё не внесены.
