# 009. Устойчивая скорость CPU

CPU и планировщик · [Каталог и правила прогона](../README.md)

## Методика

При постоянном числе потоков выполнять одинаковые порции до стабилизации температуры и скорости.

## Что измерять

Итерации/с, частота, температура, признаки power/thermal limit.

## Как читать результат

Снижение скорости вместе с аппаратным признаком ограничения позволяет различить тепловой предел и предел мощности.
