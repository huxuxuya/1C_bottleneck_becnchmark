# 073. Повторные передачи

Сеть и соединения · [Каталог и правила прогона](../README.md)

## Методика

На длинном контролируемом обмене сопоставить отдельные задержки с TCP-последовательностями и повторами. По возможности наблюдать оба конца.

## Что измерять

Время повтора, номера последовательностей, задержка операции.

## Как читать результат

Связать паузу с повторной передачей и сузить участок потери.
