# 018. Задержки кэшей и DRAM

Память и кэши CPU · [Каталог и правила прогона](../README.md)

## Методика

Увеличивать случайно перемешанную зависимую цепочку от нескольких КиБ до объёма выше LLC.

## Что измерять

Нс/доступ по размеру, при наличии промахи кэша.

## Как читать результат

Ступени кривой локализуют диапазон размеров, где дорожает обращение.

## Реализация в проекте

БенчмаркПроба018ЗадержкиКэшейDRAM.АнализироватьКривуюЗадержки(Точки) принимает минимум три возрастающих размера рабочего набора с одинаковыми стендом, алгоритмом и размером LLC. Верхний размер должен превышать LLC. Каждая точка требует три повтора зависимого случайного обхода; результат содержит медиану нс/доступ, изменение относительно предыдущего размера и, если передано, промахи LLC на доступ.

Сбор pointer-chain и аппаратных событий кэша выполняет внешний измеритель. YAxUnit проверяет кривую на контрольных данных; реальные замеры ещё не внесены.
