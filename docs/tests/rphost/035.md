# 035. Смена рабочего процесса

Рабочий процесс и кластер 1С · [Каталог и правила прогона](../README.md)

## Методика

При постоянном потоке лёгких запросов выполнить штатную смену выделенного процесса.

## Что измерять

Смена PID, ошибки, повторы, интервал без успеха.

## Как читать результат

Получить длительность перерыва и стоимость восстановления при обслуживании процесса.
