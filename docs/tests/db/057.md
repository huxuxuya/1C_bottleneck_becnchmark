# 057. Цена вторичного индекса при записи

СУБД и планы · [Каталог и правила прогона](../README.md)

## Методика

На одинаковых копиях добавлять по одному индексу. Изменять индексируемые поля одинаковых строк.

## Что измерять

CPU, байты журнала, время изменения до commit.

## Как читать результат

Дельта на строку измеряет обслуживание конкретного индекса.
