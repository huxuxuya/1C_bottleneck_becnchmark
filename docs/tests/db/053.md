# 053. Покрытие индексом

СУБД и планы · [Каталог и правила прогона](../README.md)

## Методика

На копии сравнить один результат с исходным и покрывающим индексом.

## Что измерять

Обращения к таблице, чтения/строку, план.

## Как читать результат

Исчезновение дополнительных чтений локализует цену извлечения недостающих полей.
