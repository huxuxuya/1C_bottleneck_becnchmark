# 072. RTT при заполненном канале

Сеть и соединения · [Каталог и правила прогона](../README.md)

## Методика

Держать малый обмен и ступенчато добавлять фоновую передачу в одном направлении.

## Что измерять

P95 RTT по фактическим МиБ/с.

## Как читать результат

Обнаружить очередь, которая проявляется при заполнении канала.
