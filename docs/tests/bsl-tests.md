# Тесты платформы 1С (BSL)

[Каталог проверок](README.md) · [Тесты Native API](native-tests.md) · [Статус реализации](implementation-status.md) · [Границы BSL](bsl-only-capabilities.md)

В этом списке собраны проверки из каталога `001–090`, которые должны выполняться средствами **встроенного языка (BSL) и механизмов платформы 1С** (управляемые формы, запросы, транзакции, блокировки, фоновые задания, `FileStreams`).

- Тесты, отмеченные как **Парный (BSL + Native)**, выполняются в обеих средах: BSL показывает поведение с учётом интерпретатора/платформы 1С, а [Native API](native-tests.md) — чистую скорость оборудования или ОС.
- Низкоуровневые тесты железа (`002–025`), сырого диска (`036–041`, `043–046`) и чистых сокетов (`071–076`) вынесены в [Native API](native-tests.md), так как в BSL они дают только зашумлённые прокси.
