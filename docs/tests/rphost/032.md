# 032. Рост удерживаемой памяти

Рабочий процесс и кластер 1С · [Каталог и правила прогона](../README.md)

## Методика

Повторять одинаковые циклы с освобождением объектов, измеряя после снятия нагрузки в одной фазе того же PID.

## Что измерять

Private bytes или аналог, наклон после прогрева, время операции.

## Как читать результат

Различить рост, плато и восстановление. Для диагноза утечки установить владельца удерживаемой памяти.
