# 014. Задержка удалённой NUMA-памяти

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

## Методика

Зафиксировать CPU и обходить зависимую цепочку локально и удалённо размещённых страниц. Проверить резидентность.

## Что измерять

Матрица нс/чтение для пар узлов.

## Как читать результат

Парная разница измеряет штраф удалённого доступа. Для вывода о физическом хосте проверить физическое размещение.

## Реализация в проекте

`БенчмаркПроба014УдаленнаяNUMAПамять.АнализироватьМатрицу(Измерения)` принимает полную матрицу CPU-узел × узел памяти. Каждое измерение содержит `ИдентификаторCPU`, `ЧислоЧтений`, `ДлительностьНс`, `КонтрольнаяСумма`, `ПривязкаCPUПодтверждена` и `РезидентностьПодтверждена`. Для каждой пары узлов требуется не менее трёх наблюдений. Анализатор считает медиану нс/чтение и штраф относительно локального узла для того же CPU-узла.

Сбор таймингов, закрепление CPU и проверка резидентности выполняются внешним гостевым измерителем. YAxUnit проверяет матрицу и расчёт штрафа на контрольных данных; реальные замеры ещё не внесены.
