# 034. Очередь фоновых заданий

Рабочий процесс и кластер 1С · [Каталог и правила прогона](../README.md)

## Методика

Занимать исполнителей заданиями известной длительности и ставить короткое контрольное задание.

## Что измерять

Постановка, старт, конец, число активных исполнителей.

## Как читать результат

Рост ожидания до старта при стабильном исполнении показывает границу параллелизма.
