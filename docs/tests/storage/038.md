# 038. Долговечное подтверждение

Хранилище · [Каталог и правила прогона](../README.md)

## Методика

Последовательные малые записи с явным flush. Измерить каждый полный цикл.

## Что измерять

Время записи, flush и полного цикла.

## Как читать результат

Длинные flush локализуют задержку на пути подтверждения согласно гарантиям стека.
