# 011. Ожидание vCPU

Виртуализация и NUMA · [Каталог и правила прогона](../README.md)

## Методика

При постоянном расчёте в госте синхронно записывать ready хоста либо доступный steal гостя.

## Что измерять

Работа/с, ready по vCPU, steal, интервал накопления.

## Как читать результат

Рост ожидания при падении скорости поддерживает гипотезу конкуренции. Крупное окно не разрешает короткую паузу.

## Реализация в BSL

Строка `VCPU_EFFECTIVE_RATE` сохраняет нс/итерацию повторного запуска фиксированного цикла [001](../cpu/001.md). В деталях отображаются условные МГц на той же шкале, что у 001 и 026, либо причина отсутствия пересчёта. Падение скорости показывает изменение времени исполнения цикла. Для вывода об ожидании vCPU нужны синхронные показатели ready или steal.

## Реализация в Native API

Проба `CPU_011_VCPU_WAIT` доступна через `Measure(-11)`. Она выполняет заданный объём зависимых вычислений короткими порциями и сравнивает CPU-время текущего потока с wall time. В результат входят эффективная доля CPU, скорость работы, распределение разницы wall/CPU по порциям и количество длинных пауз. На Linux дополнительно считывается изменение steal ticks из агрегатной строки `cpu` в `/proc/stat`, если файл и счётчик доступны.

Параметры: `arg1` — номинальное CPU-окно, 100–10 000 мс; `arg2` — длина одной порции CPU, 100–10 000 мкс. Число порций должно быть 100–20 000. По умолчанию — 500 мс и 1 000 мкс. Основная метрика `effectiveCpuPercentOfWall` показывает долю wall time, которую ОС учла как исполнение текущего потока. `systemStealTimeDeltaNs` является агрегатным системным счётчиком Linux, а не покомпонентной оценкой steal именно этого потока.

Это косвенная оценка ожидания: разница wall/CPU включает вытеснение и другие паузы ОС, а Linux steal относится ко всем видимым CPU. Host `%RDY`/ready из гостевой Native API недоступен; Windows и macOS возвращают `null` для steal. Результат не устанавливает причину паузы и сам по себе не доказывает конкуренцию гипервизора.

## Результаты прогонов

Native CTest/JSON прошли на macOS ARM64 и Linux ARM64; полный Native API 0.6.0 собран для семи платформ и встроен в `Template.addin`. YAxUnit на 1С 8.5.1.1621/macOS x86_64 прошёл 103 теста без failures/errors, включая CPU_011 и клиентское/серверное сохранение в файловой ИБ. Runtime в Linux/Windows 1С и отдельный `rphost` ещё не проверены. Измерения на виртуальной машине пока не внесены.
