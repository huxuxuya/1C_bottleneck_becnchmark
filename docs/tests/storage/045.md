# 045. Паузы checkpoint и writeback

Хранилище · [Каталог и правила прогона](../README.md)

## Методика

При постоянных изменениях вести редкую контрольную запись с flush. На копии сдвинуть момент checkpoint.

## Что измерять

Выбросы flush, интервалы checkpoint, объём записи.

## Как читать результат

Сдвиг пиков за сдвигом checkpoint подтверждает его влияние на путь записи.
