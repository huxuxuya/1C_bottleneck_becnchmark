# 054. Сброс сортировки на диск

СУБД и планы · [Каталог и правила прогона](../README.md)

## Методика

Увеличивать объём сортировки при фиксированной ширине строки. Проверять оператор плана.

## Что измерять

Порог строк, объём temp, время сортировки.

## Как читать результат

Первое использование диска и скачок времени определяют границу сортировки в памяти.
