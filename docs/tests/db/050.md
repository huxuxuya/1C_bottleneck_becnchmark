# 050. Оценка кардинальности

СУБД и планы · [Каталог и правила прогона](../README.md)

## Методика

Сравнить оценённые и фактические строки по узлам на данных с перекосом. На копии обновить статистику.

## Что измерять

Первая ошибка оценки, план, чтения, длительность.

## Как читать результат

Исправление оценки и снижение работы после обновления подтверждают влияние статистики.
