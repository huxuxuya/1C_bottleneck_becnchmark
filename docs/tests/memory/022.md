# 022. Давление на TLB

Память и кэши CPU · [Каталог и правила прогона](../README.md)

> **Статус BSL-only:** описанная здесь прямая метрика требует управления или счётчика ОС/гипервизора, которого BSL не предоставляет. Проект не запускает внешний сборщик и не принимает его пакет. До новой BSL-only методики точный механизм этой проверки не измеряется. См. [границу возможностей BSL](../bsl-only-capabilities.md).

## Методика

Обращаться к одной линии на страницу в случайном порядке. Сравнить обычные и крупные страницы при том же объёме и размещении.

## Что измерять

Фактический размер страниц, page walks, нс/доступ.

## Как читать результат

Снижение обходов таблиц страниц вместе с задержкой подтверждает вклад трансляции.

## Текущее состояние

Общий модуль "БенчмаркПроба022ДавлениеНаTLB" содержит BSL-код анализа переданных структур и не запускает измерительную нагрузку для этого механизма. Он не считывает OS/гипервизорные показатели и не используется раннером как источник результата. YAxUnit-проверки подтверждают только расчёт на заданных входных данных.

В режиме проекта BSL-only "размер страниц и аппаратные TLB-события" напрямую недоступна. Методика пока не даёт измерительного результата; до появления соответствующего платформенного API эту проверку нужно пометить «недоступно в BSL» либо отдельно спроектировать поведенческий BSL-прокси с более узким выводом.
