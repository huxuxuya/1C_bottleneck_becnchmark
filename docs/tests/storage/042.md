# 042. Влияние записи на чтение

Хранилище · [Каталог и правила прогона](../README.md)

## Методика

Держать редкое чтение QD=1, добавлять запись заданного темпа в отдельный файл.

## Что измерять

P95 чтения и фактические МиБ/с записи.

## Как читать результат

Указать минимальный проверенный темп записи, при котором чтение выходит за бюджет.
