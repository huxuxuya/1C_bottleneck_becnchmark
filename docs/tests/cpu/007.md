# 007. Миграция между ядрами

CPU и планировщик · [Каталог и правила прогона](../README.md)

## Методика

Внутри одного NUMA-узла переносить поток с прогретым частным кэшем. Контроль выполняет те же порции на одном ядре.

## Что измерять

Длительность первых порций, число фактических миграций.

## Как читать результат

Кратковременное удорожание вслед за переносом измеряет цену миграции для данного набора.
