# 029. Перекос нагрузки по rphost

Рабочий процесс и кластер 1С · [Каталог и правила прогона](../README.md)

## Методика

Создавать серии одинаковых сеансов при штатном распределении. Измерять активную работу каждого процесса.

## Что измерять

Сеансы, вызовы/с, CPU и p95 по PID.

## Как читать результат

Разница долей работы при сходных сеансах показывает фактический перекос кластера.
