# 071. Предел одного потока TCP

Сеть и соединения · [Каталог и правила прогона](../README.md)

## Методика

Сравнить один и несколько параллельных потоков по тому же маршруту и направлению.

## Что измерять

Суммарная полоса, окно, RTT, загрузка ядер.

## Как читать результат

Прирост с несколькими потоками локализует ограничение одиночного потока. Конкретный механизм уточнить по счётчикам.
