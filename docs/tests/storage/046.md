# 046. Расширение файла

Хранилище · [Каталог и правила прогона](../README.md)

## Методика

Сравнить запись в выделенный диапазон и запись с расширением. Для СУБД использовать заранее увеличенный файл в контроле.

## Что измерять

События роста, задержки затронутых операций.

## Как читать результат

Пики, исчезающие после предварительного выделения, локализуют цену роста.
