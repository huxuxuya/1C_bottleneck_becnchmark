# 009. Устойчивая скорость CPU

CPU и планировщик · [Каталог и правила прогона](../README.md)

## Методика

При постоянном числе потоков выполнять одинаковые порции до стабилизации температуры и скорости.

## Что измерять

Итерации/с, частота, температура, признаки power/thermal limit.

## Как читать результат

Снижение скорости вместе с аппаратным признаком ограничения позволяет различить тепловой предел и предел мощности.

## Нативное исполнение

`CPU_009_SUSTAINED_SPEED` непрерывно выполняет одинаковую зависимую целочисленную нагрузку и выдаёт ряд throughput окон. Основной показатель — медиана `medianOpsPerSecond`; сохраняются число окон, минимум, максимум и весь ряд `windowOpsPerSecond`. Длительная нагрузка выявляет изменение скорости во времени, но сама не измеряет температуру, частоту, power limit или thermal throttling. Для их причинной атрибуции нужны отдельные источники ОС/гипервизора.

Параметры: `arg1=durationMs` (50–600 000), `arg2=intervalMs` (10–10 000; не более 2 000 окон). Автоматический набор — 3 с с интервалом 250 мс. Результат сохраняется как `NCPU009C` и `NCPU009S`.
