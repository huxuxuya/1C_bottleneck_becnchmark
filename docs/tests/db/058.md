# 058. Удержание старых версий

СУБД и планы · [Каталог и правила прогона](../README.md)

## Методика

В PostgreSQL повторить цикл UPDATE с удерживаемым старым snapshot и без него. Дать время на очистку. Для SQL Server использовать метрики своего хранилища версий.

## Что измерять

Старейший snapshot, размер, страницы/запрос, очистка.

## Как читать результат

Связать рост удерживаемых версий и удорожание операции с жизнью старого snapshot.
