# 020. Полоса записи DRAM

Память и кэши CPU · [Каталог и правила прогона](../README.md)

## Методика

Писать в заранее затронутые локальные страницы, увеличивая число потоков. Зафиксировать тип записи.

## Что измерять

Полезные ГБ/с, при наличии трафик контроллера памяти.

## Как читать результат

Устойчивая граница характеризует выбранный режим записи. Сопоставить с чтением.

## Реализация в проекте

БенчмаркПроба020ПолосаЗаписиDRAM.АнализироватьПолосуЗаписи(Точки) считает полосу записи по числу потоков. Входные точки сохраняют тип записи, размер буфера и LLC, подтверждения предварительного касания и локального размещения; каждый потоковый уровень требует минимум три повтора с одной контрольной суммой.

Запись, размещение и аппаратный трафик памяти измеряет внешний исполнитель. YAxUnit проверяет единицы, нормализацию на поток и обязательные условия; реальные замеры ещё не внесены.
