# 069. RTT малого сообщения

Сеть и соединения · [Каталог и правила прогона](../README.md)

## Методика

На открытом TCP-соединении посылать последовательные малые запросы контролируемому эхо-исполнителю.

## Что измерять

RTT p50 и хвост, время обработки получателя.

## Как читать результат

Эталон малого обмена для конкретной пары конечных узлов.
