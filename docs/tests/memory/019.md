# 019. Полоса чтения DRAM

Память и кэши CPU · [Каталог и правила прогона](../README.md)

## Методика

Читать заранее размещённые локальные буферы больше LLC. Увеличивать число потоков.

## Что измерять

ГБ/с суммарно и на поток.

## Как читать результат

Плато суммарной скорости показывает предел чтения и число потоков для его достижения.

## Реализация в проекте

БенчмаркПроба019ПолосаЧтенияDRAM.АнализироватьПолосуЧтения(Точки) принимает возрастающее число потоков, одинаковый набор и минимум три повтора. Буфер должен быть больше LLC, а локальное размещение подтверждено; анализатор возвращает медиану ГБ/с суммарно и на поток.

Выделение буферов, NUMA-привязку и чтение выполняет внешний измеритель. YAxUnit проверяет вычисление полосы и отклонение буфера меньше LLC; реальные замеры ещё не внесены.
