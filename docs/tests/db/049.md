# 049. Сканирование страницы

СУБД и планы · [Каталог и правила прогона](../README.md)

## Методика

Сканировать прогретую таблицу фиксированной ширины с малым агрегированным результатом.

## Что измерять

Страницы/с, CPU/страницу.

## Как читать результат

Падение скорости при отсутствии физического чтения локализует обработку страниц.
