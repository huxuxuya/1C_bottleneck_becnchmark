# 051. Повторно используемый план

СУБД и планы · [Каталог и правила прогона](../README.md)

## Методика

Исполнить редкий и массовый параметры в обоих порядках при одинаковом прогреве.

## Что измерять

Повторное использование плана, чтения для одного значения.

## Как читать результат

Разница для одного параметра в зависимости от первого исполнения выявляет чувствительность к выбору плана.
